# Редактирование записи коллекции и wish-list

Статус: не реализовано; требует согласования деталей, не готово к реализации. Будущий этап: 3 — развитие продукта без AI. Локальный MVP этапа 1 завершён без этой операции.
Связанные документы: [правила данных](data-rules.md), [backlog](backlog.md).

## Уже согласовано

Операция запланирована для обеих таблиц на этапе 3, будет выполняться через веб-интерфейс без AI и требует подтверждения перед изменением данных. Отмена не записывает неподтверждённый проект. Посторонние записи не должны изменяться.

Для основной коллекции и wish-list выбранная запись идентифицируется постоянным ID по [правилам данных](data-rules.md#постоянный-id-записей), а не номером строки Sheets. Технический ID сохраняется. Модели записей — `CollectionRecord` и `WishlistRecord` по общему mapping. Контракт API редактирования здесь не определяется.

## Вопросы перед реализацией

- Какие поля можно менять, как отображать старые и новые значения, как проверять дубли при редактировании относительно обоих документов?
- Что делать для обеих коллекций, если выбранная запись изменилась или исчезла после открытия формы?
- Как подтверждать и проверять результат, обрабатывать сбой и повторную попытку?

Ответы владельца и техническая спецификация должны быть зафиксированы до реализации. Этот каркас не утверждает массовые операции, архивирование, историю или новый способ хранения.
