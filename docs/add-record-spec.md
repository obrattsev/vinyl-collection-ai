Операция «Добавить новую пластинку»

Цель

Найти таблицу музыкальной коллекции, собрать данные о новой физической пластинке, проверить их, исключить случайное создание дубля, показать пользователю проект записи и после подтверждения добавить ровно одну новую строку в конец таблицы. После добавления проверить результат и сообщить пользователю об успешном завершении операции.

Контекст

- Основная коллекция и wish-list хранятся в двух отдельных Google Sheets-документах.
- Одна строка основной коллекции соответствует одному приобретённому физическому экземпляру издания целиком.
- Двойной/многодисковый альбом и box set учитываются одной строкой, а не отдельной строкой на каждый диск.
- Одно и то же музыкальное произведение может присутствовать в коллекции в нескольких физических изданиях.
- Коллекцией управляет один пользователь.
- AI является основным интерфейсом чтения и изменения коллекции.
- При необходимости проверки написания, существования альбома или исполнителя, года выпуска или определения издания по фотографии разрешается использовать интернет.
- Интернет используется как дополнительный источник информации; найденные сведения, в которых нет достаточной уверенности, должны быть показаны пользователю перед записью.

Поля

1. Исполнитель — обязательное поле.
2. Альбом — обязательное поле.
3. Жанр.
4. Лейбл.
5. Год альбома — обязательное поле.
6. Год пластинки.
7. Тип издания.
8. Дата покупки.
9. Магазин покупки.
10. Цена покупки.
11. Примечание.

Пользователь также может предоставить фотографию пластинки. В этом случае AI пытается определить доступные поля автоматически и затем запрашивает недостающие обязательные данные.

Box set и многодисковые комплекты

- Одна строка соответствует физическому изданию/комплекту целиком; отдельные диски внутри комплекта отдельными строками не создаются.
- Для box set поле «Альбом» содержит официальное название самого box set.
- Поле «Исполнитель» содержит основного исполнителя комплекта. Если комплект содержит записи разных исполнителей и не имеет одного основного исполнителя, использовать «Various Artists».
- «Год альбома» означает год первоначального выпуска самого box set/релиза как самостоятельного издания, а не годы отдельных включённых в него альбомов.

Форматы данных

- Год альбома и год пластинки: "YYYY".

- Поле «Тип издания» может принимать значения «Оригинал», «Переиздание» или оставаться пустым. Пустое значение означает, что тип издания неизвестен. 

- Если определить тип издания невозможно, AI не должен угадывать его.

- «Оригинал» — физическое издание, относящееся к первоначальному выпуску альбома и не обозначенное как переиздание/reissue/repress/remaster.
- «Переиздание» — последующий выпуск ранее изданного альбома, включая явно обозначенные reissue/repress/remaster.
- Если тип издания нельзя определить достоверно, поле остаётся пустым.
- Совпадение года альбома и года пластинки само по себе недостаточно для определения «Оригинал».
- Дата покупки хранится в формате "YYYY-MM-DD": либо полная дата, либо пустое поле. Неполная дата не хранится.
- Цена покупки хранится числом в рублях; отдельное поле валюты в MVP не используется.
- Пустая цена означает, что цена неизвестна; 0 означает, что пластинка получена бесплатно.

Нормализация написаний перед сравнением

- При сравнении текстовых значений игнорировать регистр, начальные и конечные пробелы; последовательности нескольких пробелов считать одним пробелом.
- Пунктуацию, дефисы, апострофы и сами слова автоматически не нормализовать.
- Предполагаемые опечатки и альтернативные написания показывать пользователю и исправлять только после подтверждения.
- Нормализацию выполнять до поиска дублей и любого сравнения значений. Эти правила относятся к сравнению, а не к автоматическому исправлению данных таблицы.

- Если AI обнаружил возможную опечатку или альтернативное написание, которое может скрывать совпадение с существующей записью, предложить нормализованное значение. Изменение значения возможно только после подтверждения пользователя.
- Если пользователь отклоняет исправление, а неоднозначность может повлиять на определение дубля, добавление блокируется до уточнения. Исходное сомнительное написание нельзя использовать для обхода проверки дублей.

Правила и ограничения

1. Перед созданием записи проверить таблицу на потенциальные дубли.
2. При поиске потенциального дубля сначала сравнивать "Исполнитель + Альбом". При их совпадении для различения физических изданий использовать максимально доступные признаки "Лейбл + Год пластинки + Тип издания". Если заполненные в обеих записях признаки издания различаются, записи считаются разными изданиями.
3. Если найден потенциальный дубль, новую запись не добавлять. Если данных недостаточно, чтобы доказать, что это другое издание, показать найденные записи пользователю и запросить уточнение. Подтверждение пользователя само по себе не разрешает создание дубля.
4. Проверять написание исполнителя, альбома и лейбла.
5. Не исправлять предложенные пользователем значения без подтверждения.
6. Контролировать консистентность написания исполнителей, альбомов и лейблов с уже существующими значениями таблицы.
7. Новые записи добавлять только в конец таблицы.
8. Не перезаписывать существующие строки.
9. Не изменять и не удалять существующие записи без отдельного подтверждения пользователя.
10. Перед записью показывать пользователю полный проект новой строки.
11. Допускать прямые команды без предварительного входа; команда "Начинаем работу с Коллекцией" также открывает общий режим работы.
12. Завершать режим работы после команды "Завершаем работу с Коллекцией", отменяя текущую незавершённую операцию согласно разделу «Отмена незавершённой операции».
13. Для фото правило: если AI не уверен в распознанном значении, оно должно маркироваться как предположение, а не попадать в проект записи как подтверждённый факт.
	
Вход в пользовательские сценарии

- Прямые пользовательские команды разрешены; предварительная команда «Начинаем работу с Коллекцией» не обязательна.
- Команда «Начинаем работу с Коллекцией» остаётся допустимым способом войти в общий режим работы.
- Если пользователь говорит «Добавить пластинку» или эквивалент и не указывает wish-list, целевой таблицей считается основная коллекция.
- Для добавления в wish-list пользователь должен явно указать wish-list.
- Если намерение или целевая таблица всё же неоднозначны, AI должен запросить уточнение, а не угадывать.

Отмена незавершённой операции

- Пользователь может отменить текущую незавершённую операцию командой «Отмена» или однозначным эквивалентом.
- «Завершаем работу с Коллекцией» также отменяет текущую незавершённую операцию, если такая существует.
- При отмене текущий неподтверждённый проект записи или поискового запроса отбрасывается.
- Отменённый проект не записывается в Google Sheets и не сохраняется для автоматического продолжения позже.
- После отмены пользователь может начать новую операцию.

Алгоритм

Старт

Определить действие и целевую таблицу по правилам раздела «Вход в пользовательские сценарии». После общей команды начала работы уточнить действие, если оно не указано. Если выбран поиск, перейти к соответствующей спецификации; если добавление в основную коллекцию — предложить способ добавления:

- по фотографии;
- вручную.

Добавление по фотографии

1. Проанализировать фотографию.
2. Определить поля, которые можно достоверно заполнить.
3. При необходимости использовать интернет для проверки найденной информации.
4. Показать данные, полученные из фотографии и внешних источников.
5. Запросить недостающие обязательные поля.
6. При необходимости запросить остальные данные и примечание.
7. Нормализовать значения для сравнения и проверить возможные дубли.
8. Проверить написание исполнителя, альбома и лейбла и консистентность с существующей коллекцией.
9. Сформировать полный проект новой строки.
10. Показать проект пользователю.
11. Запросить подтверждение либо корректировку.

Ручное добавление

1. Запросить обязательные поля.
2. Спросить, хочет ли пользователь заполнить дополнительные поля.
3. Получить выбранные дополнительные данные.
4. Нормализовать значения для сравнения и проверить возможные дубли.
5. Проверить написание исполнителя, альбома и лейбла и консистентность с существующей коллекцией.
6. Сформировать полный проект новой строки.
7. Показать проект пользователю.
8. Запросить подтверждение либо корректировку.

Запись

После подтверждения пользователя:

1. Повторно нормализовать значения для сравнения и проверить отсутствие потенциального дубля.
2. Проверить обязательные поля и форматы данных.
3. Добавить ровно одну новую строку в конец таблицы.
4. Не изменять остальные строки.
5. Перечитать добавленную строку из Google Sheets.
6. Сравнить её с подтверждённым проектом записи.

Предположения AI и подтверждение значений

- Неподтверждённое предположение AI не записывается в таблицу.
- Необязательное неподтверждённое поле оставляется пустым.
- Обязательное поле необходимо уточнять до получения подтверждённого значения.
- Подтверждение пользователем полного проекта строки считается подтверждением всех явно показанных в проекте значений, в том числе первоначально предложенных AI. До подтверждения предположения должны быть явно отмечены как предположения.

Подтверждение пользователя обязательно

- перед добавлением новой строки;
- перед исправлением предложенных пользователем значений;
- перед изменением существующей строки;
- перед удалением существующей строки.

Результат

В конец таблицы добавлена ровно одна новая строка, соответствующая одному приобретённому физическому экземпляру издания целиком.

Проверка результата

После записи AI должен убедиться, что:

- появилась ровно одна новая строка;
- строка находится в конце таблицы;
- обязательные поля заполнены;
- значения совпадают с подтверждённым проектом;
- форматы данных соблюдены;
- существующие строки не были изменены.

Критерии успеха

Операция считается успешной, если:

- новая пластинка корректно добавлена;
- потенциальный дубль не создан;
- существующие данные не изменены;
- добавленная строка совпадает с подтверждённым проектом;
- пользователь уведомлён об успешном завершении операции.
