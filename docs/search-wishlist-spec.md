Операция «Поиск в wish-list или получение всего списка»

Цель

Найти wish-list музыкальной коллекции, определить режим работы — получение всего wish-list либо поиск одной или нескольких записей по заданным критериям — выполнить операцию без изменения данных и вернуть результат в табличной форме.

Контекст

- Wish-list хранится в Google Sheets.
- Основная коллекция и wish-list хранятся в двух отдельных Google Sheets-документах.
- Одна строка wish-list соответствует одной желаемой физической пластинке или конкретному желаемому изданию.
- Одно и то же музыкальное произведение может присутствовать в wish-list в нескольких физических изданиях.
- Коллекцией и wish-list управляет один пользователь.
- AI является основным интерфейсом чтения wish-list.
- Поиск и получение списка не изменяют данные.
- При необходимости проверки написания исполнителя, альбома, лейбла, года выпуска или определения информации по фотографии разрешается использовать интернет.
- Интернет используется только как дополнительный источник для уточнения поисковых критериев, а не как замена данным wish-list.

Поиск может выполняться по любому полю или комбинации полей:

1. Исполнитель.
2. Альбом.
3. Жанр.
4. Лейбл.
5. Год альбома.
6. Год пластинки.
7. Тип издания.
8. Примечание.
9. Ссылка на онлайн-магазин.

Пользователь также может предоставить фотографию пластинки. В этом случае AI пытается определить доступные признаки и использует их как критерии поиска.

Форматы данных

- Год альбома и год пластинки: "YYYY".
- Поле «Тип издания» может принимать значения «Оригинал», «Переиздание» или оставаться пустым.
- Пустое значение поля «Тип издания» означает, что тип издания неизвестен.
- Поле «Ссылка на онлайн-магазин» должно содержать корректный URL или быть пустым.

Правила и ограничения

1. Операция является только операцией чтения.
2. Запрещено добавлять, изменять, удалять или перезаписывать строки.
3. Пользователь может:
   - получить весь wish-list;
   - найти одну запись;
   - найти несколько записей по одному или нескольким критериям.
4. Поиск может выполняться:
   - по одному полю;
   - по комбинации нескольких полей;
   - по точному значению;
   - по частичному совпадению, если пользователь явно это допускает или ввод не является полным.
5. Проверять написание исполнителя, альбома и лейбла.
6. Контролировать консистентность поисковых значений с существующими значениями wish-list.
7. Если пользователь указал значение, похожее на существующее, но написанное иначе, показать найденный вариант и использовать исправленное значение только после подтверждения.
8. Если пользователь запросил весь wish-list, отдельное подтверждение не требуется.
9. Если пользователь сформулировал однозначные критерии поиска, отдельное подтверждение перед поиском не требуется.
10. Если критерии неоднозначны или были определены по фотографии, показать проект поискового запроса и запросить подтверждение либо корректировку.

Алгоритм

Старт

После команды "Начинаем работу с Коллекцией" определить действие пользователя.

Если пользователь хочет работать с wish-list, предложить:

- показать весь wish-list;
- выполнить поиск в wish-list.

Получение всего wish-list

1. Найти отдельный Google Sheets-документ wish-list.
2. Прочитать все существующие строки.
3. Не изменять данные.
4. Если wish-list пуст, вернуть сообщение:
   "Wish-list пуст".
5. Если записи есть, вернуть все записи в табличной форме.

Поиск по фотографии

1. Проанализировать фотографию.
2. Определить поля, которые можно достоверно распознать.
3. Отделить достоверные значения от предположений.
4. При необходимости использовать интернет для проверки распознанной информации.
5. Показать пользователю найденные значения и предположения.
6. При необходимости запросить дополнительные критерии поиска.
7. Проверить написание исполнителя, альбома и лейбла.
8. Сопоставить значения с существующими значениями wish-list.
9. Сформировать проект поискового запроса.
10. Показать проект пользователю.
11. Запросить подтверждение либо корректировку.
12. После подтверждения выполнить поиск.

Ручной поиск

1. Получить от пользователя один или несколько критериев поиска.
2. Определить, по каким полям необходимо искать.
3. При необходимости уточнить дополнительные критерии.
4. Проверить написание исполнителя, альбома и лейбла.
5. Сопоставить значения с существующими значениями wish-list.
6. Если критерии однозначны — выполнить поиск.
7. Если критерии неоднозначны — сформировать проект поискового запроса.
8. Показать проект пользователю.
9. Запросить подтверждение либо корректировку.
10. После подтверждения выполнить поиск.

Поиск

При выполнении поиска:

1. Проверить форматы переданных значений.
2. Не изменять данные wish-list.
3. Применить все заданные критерии одновременно.
4. Вернуть все записи, соответствующие условиям.
5. Если совпадений нет — вернуть сообщение:
   "По поисковому запросу записей в wish-list не найдено".

Формат результата

Если записи найдены, вернуть результат в табличной форме.

По умолчанию показывать:

Исполнитель| Альбом| Жанр| Лейбл| Год альбома| Год пластинки| Тип издания| Примечание| Ссылка на онлайн-магазин

Если пользователь запросил весь wish-list, вернуть все строки в этом формате.

Если найдено несколько физических изданий одного альбома, показать каждое отдельной строкой.

Результат

Один из вариантов:

- полный wish-list в табличной форме;
- таблица с одной или несколькими записями, соответствующими поисковому запросу;
- сообщение "Wish-list пуст";
- сообщение "По поисковому запросу записей в wish-list не найдено".

Проверка результата

После выполнения операции AI должен убедиться, что:

- при получении всего wish-list возвращены все существующие строки;
- при поиске применены именно согласованные критерии;
- форматы данных интерпретированы корректно;
- результат содержит только подходящие записи;
- все подходящие записи включены в результат;
- данные wish-list не были изменены;
- данные основной коллекции не были изменены.

Критерии успеха

Операция считается успешной, если:

- пользователь получил весь wish-list или корректный результат поиска;
- при отсутствии записей или совпадений пользователь получил понятное сообщение;
- существующие данные wish-list и основной коллекции не были изменены.
