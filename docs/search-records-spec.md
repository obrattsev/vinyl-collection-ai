Операция «Поиск пластинок в коллекции»

Цель

Найти таблицу музыкальной коллекции, получить от пользователя критерии поиска, при необходимости уточнить или нормализовать их, выполнить поиск без изменения данных и вернуть результат в табличной форме.

Поиск может использоваться как для одной конкретной пластинки, так и для выборки нескольких записей по одному или нескольким полям.

Контекст

- Коллекция хранится в Google Sheets.
- Одна строка соответствует одной физической пластинке.
- Одно и то же музыкальное произведение может присутствовать в коллекции в нескольких физических изданиях.
- Коллекцией управляет один пользователь.
- AI является основным интерфейсом чтения коллекции.
- Поиск не изменяет данные.
- При необходимости проверки написания исполнителя, альбома, лейбла, года выпуска или определения информации по фотографии разрешается использовать интернет.
- Интернет используется только как дополнительный источник для уточнения поисковых критериев, а не как замена данным коллекции.

Поиск может выполняться по любому полю или комбинации полей:

1. Исполнитель.
2. Альбом.
3. Жанр.
4. Лейбл.
5. Год альбома.
6. Год пластинки.
7. Тип издания.
8. Дата покупки.
9. Магазин покупки.
10. Цена покупки.
11. Примечание.

Пользователь также может предоставить фотографию пластинки. В этом случае AI пытается определить доступные признаки и использует их как критерии поиска.

Форматы данных

- Год альбома и год пластинки: "YYYY".
- Поле «Тип издания» может принимать значения «Оригинал», «Переиздание» или оставаться пустым.
- Пустое значение поля «Тип издания» означает, что тип издания неизвестен.

Правила и ограничения

1. Поиск является только операцией чтения.
2. Во время поиска запрещено добавлять, изменять, удалять или перезаписывать строки.
3. Поиск может выполняться:
   - по одному полю;
   - по комбинации нескольких полей;
   - по точному значению;
   - по частичному совпадению, если пользователь явно это допускает или ввод не является полным.
4. Проверять написание исполнителя, альбома и лейбла.
5. Контролировать консистентность поисковых значений с уже существующими значениями таблицы.
6. Если пользователь указал значение, похожее на существующее, но написанное иначе, показать найденный вариант и использовать исправленное значение только после подтверждения пользователя.
7. Если пользователь сформулировал однозначные критерии поиска, отдельное подтверждение перед выполнением поиска не требуется.
8. Если критерии неоднозначны или были автоматически определены по фотографии, показать пользователю проект поискового запроса и запросить подтверждение либо корректировку.
9. Начинать режим работы после команды "Начинаем работу с Коллекцией".
10. Завершать режим работы после команды "Завершаем работу с Коллекцией".

Алгоритм

Старт

После команды "Начинаем работу с Коллекцией" определить действие пользователя.

Если пользователь хочет выполнить поиск, предложить способ:

- по фотографии;
- вручную.

Поиск по фотографии

1. Проанализировать фотографию.
2. Определить поля, которые можно достоверно распознать.
3. Отделить достоверные значения от предположений.
4. При необходимости использовать интернет для проверки распознанной информации.
5. Показать пользователю найденные значения и предположения.
6. При необходимости запросить дополнительные критерии поиска.
7. Проверить написание исполнителя, альбома и лейбла.
8. Сопоставить значения с существующими значениями таблицы.
9. Сформировать проект поискового запроса.
10. Показать проект пользователю.
11. Запросить подтверждение либо корректировку.
12. После подтверждения выполнить поиск.

Ручной поиск

1. Получить от пользователя один или несколько критериев поиска.
2. Определить, по каким полям необходимо искать.
3. При необходимости уточнить дополнительные критерии.
4. Проверить написание исполнителя, альбома и лейбла.
5. Сопоставить значения с существующими значениями таблицы.
6. Если критерии однозначны — выполнить поиск.
7. Если критерии неоднозначны — сформировать проект поискового запроса, показать пользователю и запросить подтверждение либо корректировку.
8. Выполнить поиск после подтверждения.

Поиск

При выполнении поиска:

1. Проверить форматы переданных значений.
2. Не изменять данные таблицы.
3. Применить все заданные критерии одновременно.
4. Вернуть все записи, соответствующие условиям.
5. Если совпадений нет — вернуть сообщение:
   "По поисковому запросу пластинок не найдено".

Формат результата

Если записи найдены, результат вернуть в табличной форме.

По умолчанию показывать:

Исполнитель| Альбом| Жанр| Лейбл| Год альбома| Год пластинки| Тип издания

Если пользователь искал по полям покупки или примечанию, дополнительно показать релевантные поля:

- Дата покупки;
- Магазин покупки;
- Цена покупки;
- Примечание.

Если найдено несколько физических изданий одного альбома, показать каждое отдельной строкой.

Результат

Один из двух вариантов:

- таблица с пластинкой или пластинками из коллекции, соответствующими поисковому запросу;
- сообщение "По поисковому запросу пластинок не найдено".

Проверка результата

После выполнения поиска AI должен убедиться, что:

- применены именно согласованные критерии поиска;
- форматы данных интерпретированы корректно;
- результат содержит только подходящие записи;
- все подходящие записи включены в результат;
- данные коллекции не были изменены.

Критерии успеха

Операция считается успешной, если:

- поиск выполнен по корректным критериям;
- пользователь получил все подходящие записи;
- при отсутствии совпадений пользователь получил понятное сообщение;
- существующие данные коллекции не были изменены.
