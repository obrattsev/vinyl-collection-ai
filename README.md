# Vinyl Collection AI

AI-помощник для ведения домашней коллекции виниловых пластинок.

## Цель

Управлять коллекцией через AI с хранением данных в Google Sheets.

## Возможности MVP

- просмотр и поиск по коллекции;
- добавление новых пластинок;
- добавление пластинки по фотографии;
- редактирование ранее добавленных записей основной коллекции и wish-list;
- удаление ранее добавленных записей основной коллекции и wish-list;
- wish-list пластинок;
- проверка потенциальных дублей;
- контроль консистентности данных;
- поиск информации об исполнителях, альбомах и изданиях;
- подтверждение пользователем изменений перед записью.

Редактирование и удаление остаются в MVP для основной коллекции и wish-list. Их отдельные спецификации будут подготовлены перед реализацией этих операций.

Проверка дублей, проверка консистентности и интернет-поиск информации об исполнителях, альбомах и изданиях в текущем MVP являются внутренними возможностями описанных операций, а не самостоятельными пользовательскими операциями.

## Хранение данных

Основная коллекция и wish-list хранятся в двух отдельных Google Sheets-документах.

Одна строка основной коллекции соответствует одному приобретённому физическому экземпляру издания целиком. Двойной/многодисковый альбом и box set учитываются одной строкой, а не отдельной строкой на каждый диск.

AI используется как основной интерфейс для чтения и изменения коллекции.
