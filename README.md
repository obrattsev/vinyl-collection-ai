# Vinyl Collection AI

Приложение для ведения домашней коллекции виниловых пластинок. Название проекта сохранено; AI появится на третьем этапе.

## Этапы

1. **Локальный MVP без AI.** Один владелец, веб-интерфейс с таблицами, формами и фильтрами. Просмотр и поиск в коллекции и wish-list, ручное добавление, редактирование и удаление, проверки дублей и форматов, подтверждение изменений и отмена. Хранилище — два отдельных Google Sheets-документа. Локальный запуск требует интернета для Google Sheets.
2. **Доступ через интернет.** После реализации и тестирования первого MVP: публикация на собственном VPS, HTTPS, полный доступ владельца и гостевой просмотр разрешённых данных. Авторизацию и состав гостевых данных согласовать до реализации. Отдельные коллекции других пользователей не предусмотрены.
3. **AI-чат.** Дополнительный интерфейс к существующим операциям; формы и кнопки сохраняются. Фото, уточнение сведений в интернете и неоднозначных написаний — только на этом этапе. Провайдер, расходы и подробности реализации ещё не выбраны.

## Границы первого MVP

- Коллекция и wish-list доступны через отдельные разделы; добавление выполняется в явно выбранный раздел.
- Дополнительный жанр включён в модель; поиск по жанру проверяет оба жанра.
- Поиск по тексту имеет явные режимы «точное совпадение» и «содержит». Годы, дата, цена и тип издания сравниваются точно; диапазоны не входят в MVP.
- Изменения требуют предварительного показа проекта и подтверждения. Отмена отбрасывает несохранённый проект без автоматического продолжения.
- Потенциальный дубль блокирует добавление; подтверждение не отменяет эту проверку.
- Смысловая проверка названий, распознавание фото, AI и интеграции с музыкальными каталогами в первый этап не входят. Пользователь вводит сведения самостоятельно.
- Проверки дублей и консистентности встроены в операции; самостоятельная проверка всей коллекции не включена.

Первый этап завершён только после реализации всех его согласованных операций и проверки успешных сценариев, отмены, ошибок чтения/записи и защиты от повторной записи. Тесты локальных данных не заменяют проверку интеграции с Sheets.

## Локальный прототип

Текущее состояние реализации — первый прототип просмотра. Это промежуточный результат, а не завершённый локальный MVP.

Только просмотр вымышленных тестовых данных, без внешних сервисов и изменения коллекции. Требуется Python 3 и браузер. Из корня репозитория:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory prototype
```

Откройте http://127.0.0.1:8000/ и нажмите «Покажи коллекцию». Данные находятся в `prototype/data/collection.json`. Для проверки пустого списка временно замените содержимое на `[]`, повторно нажмите кнопку, затем восстановите данные. Остановка сервера — `Ctrl+C`.

## Первая итерация правил данных

`src/collection-rules.mjs` содержит чистые функции сравнения для уже проверенных записей: нормализацию, потенциальные дубли, проверки добавления в обе таблицы и сравнение жанров. Полная валидация полей, интерфейс и Google Sheets ещё не подключены к этому модулю.

Тесты: установленный Node.js с поддержкой встроенного test runner, команда `node --test tests/collection-rules.test.mjs`.
