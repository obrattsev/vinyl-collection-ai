# Просмотр и поиск в коллекции

Статус: согласовано для интерфейса без AI. Этап: 1.
Связанные документы: [правила данных](data-rules.md), [будущий AI](ai-stage.md).

## Поведение

Получение всего списка возвращает все строки без подтверждения. Поиск и просмотр ничего не изменяют ни в одном документе. Список берётся из соответствующего Google Sheets-документа.

Ручной интерфейс содержит только четыре критерия: Исполнитель, Альбом, Год альбома и Жанр. Их можно использовать отдельно или одновременно. Для каждого из критериев Исполнитель, Альбом и Жанр пользователь явно выбирает режим «точное совпадение» (`exact`) или «содержит» (`contains`). Автоматического угадывания режима нет. Год альбома ищется только по точному совпадению в формате YYYY.

Текст сравнивается после общей нормализации: `exact` — совпадение полного значения, `contains` — поиск подстроки. Запись должна соответствовать всем заполненным критериям (И). Один критерий Жанр проверяется одновременно по полям Жанр и Дополнительный жанр в выбранном режиме; достаточно совпадения любого из них (ИЛИ). Отдельного пользовательского критерия Дополнительный жанр нет. Диапазоны не поддерживаются.

Поиск по остальным полям основной коллекции не реализуется в ручном интерфейсе этапа 1. Ограничение относится только к критериям интерфейса и не удаляет поля из модели данных.

Пустой критерий (в том числе текст, пустой после общей нормализации) означает, что фильтр по соответствующему полю не применяется. Он не означает поиск записей с пустым полем. Если непустых критериев нет, возвращается весь список.

Сначала проверить форматы непустых критериев. При корректных критериях выполнить поиск без дополнительного подтверждения. Применять только техническую нормализацию по общим правилам данных; смысловое исправление написаний и AI-подобные проверки относятся к этапу 3. Кнопка отмены отбрасывает неподтверждённый проект критериев; можно начать новую операцию.

## Результат

Все подходящие строки, каждое физическое издание отдельно, в таблице:

Исполнитель | Альбом | Жанр | Дополнительный жанр | Лейбл | Год альбома | Год пластинки | Тип издания

Пустой полный список: «Коллекция пуста».
Нет совпадений поиска: «По поисковому запросу пластинок не найдено».

## Приёмка

Возвращены все и только соответствующие записи, применены все выбранные критерии, форматы интерпретированы корректно. Исходные данные не изменились. Пустой список отличается от отсутствия совпадений; ошибка чтения не отображается как пустой список.

Гибкий поиск естественным языком, более сложные запросы по данным коллекции и поиск по фотографии — AI-интерфейс этапа 3. Подробности расширенного поиска требуют спецификации; см. [AI-этап](ai-stage.md) и [backlog](backlog.md).
