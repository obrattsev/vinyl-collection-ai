## Known limits and remaining scope

Обязательный независимый S3 deletion ledger, Yandex Object Storage и Limited mode — **superseded** решением владельца. Самостоятельное удаление аккаунта остаётся завершённой функцией 4C: транзакционное удаление, отзыв сессий, durable Cover cleanup, проверки ownership/concurrency. Существующие restore quarantine/recovery сохраняются.

Принятый остаточный риск: восстановление backup, созданного до удаления, способно вернуть аккаунт, данные и reservations. Без независимой истории нельзя гарантировать выявление всех удалений. Quarantine/recovery не реконструируют неизвестные удаления. Это не release blocker; применимые требования к персональным данным сохраняются. Новые сервисы/ledger для устранения риска не добавляются.

Отчёт не подтверждает проверки, остановленные владельцем, и не заменяет отсутствующие исходные operation logs. Подтверждение владельца и проверенный runtime достаточны для документационного закрытия; незавершённый rollout не возобновляется.
